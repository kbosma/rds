RDS — documentatie-index

RDS = Reis Dossier Systeem: een multi-tenant SaaS voor reisorganisaties om boekingen (dossiers) te beheren, documenten en e-mails te genereren en betalingen via Mollie af te handelen. Eén Spring Boot-backend, twee Angular-apps.

Nieuwe sessie? Lees in deze volgorde (±10 minuten):
1. dit bestand (index + snelle feiten hieronder)
2. overview.md — wat het systeem doet, voor wie, en hoe het in elkaar zit
3. working-agreements.md — hoe er met de gebruiker gewerkt wordt (taal, git, tests, grenzen)
4. open-items.md — wat nog openstaat

Daarna alleen het document dat bij de taak past (tabel hieronder). De regels in CLAUDE.md (repo-root) blijven leidend; deze map is de uitleg erbij.

Leesversies (HTML) en diagrammen

Elk document hier heeft een leesversie ernaast (<naam>.html): tabellen met lijnen en afwisselende rijkleuren, een inhoudsopgave, licht/donker thema en getekende diagrammen (Mermaid: flowcharts, sequence-, state- en ER-diagrammen). De .md is de bron; na een wijziging maak je de HTML opnieuw:

python3 docs/tools/md-naar-html.py docs/*.md

Een diagram schrijf je in de .md als codeblok met de taal mermaid; GitHub toont het ook. Gebruik er een waar het iets verheldert (een stroom, een volgorde van stappen, een toestandsverloop, een datamodel), niet om tekst te herhalen.

Snelle feiten
BackendSpring Boot 4.0.3, Java 21, Jetty (poort 8666, context-path /rds), JPA (ddl-auto: validate), Flyway (V1–V16), MapStruct, PostgreSQL 17 (rdsdb)
Frontendsfrontend-employee (medewerkers, dev-poort 4200) en frontend-booker (klanten, dev-poort 4300); Angular 22, standalone + signals, Angular Material, ngx-translate (nl/en), TypeScript 6
Pakketten (backend)nl.puurkroatie.rds.{auth, booking, mollie, bookerportal, email, docgen, common}
Multi-tenantelke tenant-entiteit heeft tenant_organization; filtering via TenantContext (zie security.md)
Rechten in de UIop authorities, nooit op rollen
RollenADMIN (systeembeheer), MANAGER (eigen organisatie, volledig), EMPLOYEE (eigen organisatie, beperkt)
TemplatingFreeMarker, afgeschermd; één model voor e-mail én Word (zie templates.md)
BetalingenMollie (webhook via NGINX op het publieke IP)
Tests (stand 21-10-2026)backend 718 (JUnit 5/Mockito/MockMvc), employee-frontend 556 specs, booker-frontend 158 specs (Jasmine/Karma, Firefox headless)

Over deze map

  • Taal: Nederlands; technische termen, identifiers en code blijven zoals ze zijn.
  • Feiten zijn waar mogelijk uit de code gehaald (bv. de endpointtabel in api-examples.md). Wijkt een document af van de code, dan wint de code — corrigeer het document.
  • CLAUDE.md (repo-root) verwijst naar deze index en naar de afzonderlijke documenten; de bestandsnamen zijn daarom stabiel. Nieuw document toevoegen ⇒ ook hier in de tabel en in de lijst "Context gebruik" van CLAUDE.md.
